# 巴巴塔

让乐奇眼镜连接你自己的 AI 助手。
这里包含眼镜客户端、云端服务、持久对话、服务器记忆和照片存储。
每个人用自己的凭据，部署一份全新的实例。

[English](README.md) · [给 coding agent 的安装指南](docs/AGENT_INSTALL.md) · [眼镜客户端](mobile/rokid-aiui/README.md)

## 功能

- 前台连续中文语音对话。回答播完后，自动继续听下一句。
- 服务器结合对话决定是否拍一张照片。眼镜检查指令后拍照，并回传同一会话。
- 对话保存在服务器，重启后可以继续。Codex 后端可整理和检索记忆，明确说“记住：……”可更新个人资料。
- 收到的照片可保留为私有 JPEG 文件，并记录描述和清单。

记忆整理依赖后端、模型和后台处理。
回答成功不代表已经形成记忆；上传成功也不代表照片已写入文件。

## 交给 agent 安装

把这段话连同仓库地址发给你的 coding agent：

> 先读 AGENTS.md 和 docs/AGENT_INSTALL.md。用我的服务器、模型凭据和独立资料部署巴巴塔。为我的乐奇眼镜准备私有工程，放在源码仓库之外。验证真实模型回答、重启后查回、照片落盘和两人隔离。最后说明哪些眼镜操作需要我配合验收。

安装指南会先收集服务器、域名、模型凭据和个人标识。
密钥、私有眼镜包、聊天、记忆和照片都不能提交 Git。
不需要导入原作者的任何资料。

## 国际版眼镜

用自己的乐奇账号登录 [AIUI Global](https://aiui-global.rokid.com/)。
agent 从 `mobile/rokid-aiui` 生成带个人配置的私有工程，再导入、打包并保存。
手机 Hi Rokid 使用同一账号，更新眼镜资源。
操作以[官方快速入门](https://js.rokid.com/AIUI/guide/quickstart/quickstart?lang=en-US&version=latest)为准。

新用户的国际版眼镜仍需实测。
自动后台记忆、播报打断和退出清理也需在新部署上分别验收。
本地测试、网页预览和接口成功不能代替眼镜验收。
